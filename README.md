# Помічник для Кобзи

Розв'язувач для гри [Кобза](https://kobzaapp.github.io/) — української версії Wordle.

Застосунок пропонує слово, ви граєте його в Кобзі, тоді натискаєте на клітинки,
щоб позначити кольори, які вам показала гра. Далі він звужує список кандидатів
і пропонує наступне слово.

## Як це працює

- **Оцінювання.** Для поточного списку кандидатів рахується частка слів, що
  містять кожну літеру. Оцінка слова — сума частот його *унікальних* літер, тож
  повторена літера не додає балів двічі. Рекомендується слово з найвищою оцінкою.
- **Фільтрування.** Зелена літера фіксує позицію; жовта означає, що літера є в
  слові, але не на цій позиції; чорна виключає літеру — окрім випадку, коли та
  сама літера в цій же спробі позначена зеленим або жовтим (тоді обмеження не
  застосовується, щоб не викинути правильну відповідь).
- **Стан.** Окремого сховища немає: кожна спроба фільтрує тих, хто вижив
  попередньо, тож обмеження накопичуються самі.

## Результати

На вибірці з 301 слова зі словника: розгадано 288 (95.7%), у середньому за 4.08 спроби.
Перше слово — `орані`.

Файл `words.js` узято без змін, а він містить службові маркери розділів
(`*топонiми*`, `*власнi назви*`, `*custom*`) поряд зі словами, тож при
завантаженні лишаються тільки записи з п'яти літер — 7816 слів.

```
node test.js
```
